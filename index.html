Installer Code secret sur mon appareil

Votre jeu, depuis son icône.

Installez Code secret depuis votre navigateur pour l’ouvrir comme une application. L’installation est facultative et gratuite.

Utilisez le menu de votre navigateur et suivez les étapes ci-dessous.

  1. Android · Chrome : ouvrez le menu ⋮ puis « Installer l’application » ou « Ajouter à l’écran d’accueil », selon ce qui est proposé.
  2. iPhone · Safari : ouvrez le menu de partage puis « Sur l’écran d’accueil » ou « Ajouter à l’écran d’accueil ».
  3. Ordinateur · Chrome ou Edge : utilisez l’icône d’installation dans la barre d’adresse ou la commande d’installation du menu.

Confirmez le nom Code secret et l’icône aux quatre pions colorés, puis ouvrez le jeu depuis cette icône. Les commandes varient selon le navigateur.

Après un premier chargement en ligne réussi, le jeu peut s’ouvrir hors connexion. La partie en cours n’est pas sauvegardée : rouvrir ou recharger démarre une nouvelle partie.
